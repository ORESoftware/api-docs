Quick start

1. Declare the route map

The operation key is the stable identity. Paths, methods, schemas, transports, framing, delivery and aliases contribute to the semantic digest.

{
  "schema_version": "1.0.0",
  "service": "inventory-api",
  "map": {
    "get_item": {
      "path": "/v1/items/{id}",
      "methods": ["GET"],
      "transports": ["http", "tcp", "websocket"]
    }
  }
}

2. Send the same v1 envelope

WebSocket and TCP carry the call object directly; HTTP maps the same operation to method/path/query/headers/body. NATS adapters use the declared subject externally.

{
  "v": 1,
  "op": "call",
  "id": "demo-1",
  "key": "get_item",
  "transport": "websocket",
  "path": { "id": "item-42" }
}

3. Receive a transport-neutral receipt

{
  "v": 1,
  "op": "receipt",
  "id": "demo-1",
  "key": "get_item",
  "transport": "websocket",
  "ok": true,
  "status": 200,
  "body": { "id": "item-42" }
}

4. Use typed client surfaces

// Rust
let call = ores_api_docs::RpcCall::new("demo-1", "get_item");
let line = call.to_ndjson()?;

// TypeScript
const route = Routes["get_item"];
// use route metadata instead of hard-coding a path

Envelope sanity playground

Edit a call or receipt and run the lightweight browser sanity check. This is intentionally not a substitute for repository admission: CI executes the real TJSV implementation plus language/runtime harnesses.

Choose an example, edit it, then check the envelope.

Production contract enforcement belongs at the admission boundary. The browser helper only catches obvious v1 envelope mistakes so the site stays dependency-free and never loads validators or scripts from a CDN.

Where this custom RPC fits

HTTP JSON services

Generate OpenAPI/OpenRPC docs and typed operation metadata from the same normalized route inventory that the server admits.

WebSocket clients

Carry the same call/receipt objects as text frames without inventing a second operation naming system.

TCP services

Use NDJSON or four-byte big-endian length-prefixed JSON while retaining identical operation keys and envelope semantics.

NATS adapters

Bind the same JSON envelope to reviewed subjects while keeping socket/broker ownership outside this crate.

Cross-language SDKs

Compare generated and native runtime behavior across Rust, TypeScript, Dart, Gleam, Go and the RIDL v2 emitter set.

Deployment drift defense

Use the shared semantic SHA-256 to reject docs, routes or client surfaces that do not match the deployed contract.
